# 事務事業優先度評価ツール スターターキット

行政が公表しているPDF形式の「事務事業評価シート」を住民が読みやすい形に構造化し、住民自身が個々の事業を評価・共有できるツールを、任意の自治体向けに作るためのビルド一式です。

すでに動いている本体ツール（住民向け）は [onuma-spec/jimujigyou-hyoka](https://github.com/onuma-spec/jimujigyou-hyoka) で公開しています。このリポジトリは、その仕組みを**自分の自治体でも作りたい人向け**の制作キットです。

実例として[北本市版（完成見本）](https://onuma-spec.github.io/jimujigyou-hyoka/kitamoto_index.html)を触ってみてください。

---

## ビルドの流れ

以下の①〜④は、Claude Code等のAIコーディング支援に本リポジトリ一式を渡し、`スターターキット.md`・`fixed_prompt.md`を指示書として読み込ませて実行してもらう前提です。人が1つ1つ手作業でコードを書くものではありません（判断が必要な場面ではAIから都度確認を求められます）。

- **土台（`fixed_prompt.md`・`スターターキット.md`）**：特定のフェーズに属さず、①〜④すべての作業中に立ち返って参照する。`fixed_prompt.md`が唯一の権威ある本体（データの型・4フェーズの手順・品質基準・環境設定を定義）、`スターターキット.md`はその読み方ガイド（環境設定で②独立運用を選ぶ案内・ファイル名の読み替え等）
- **フェーズ①（取得・抽出）**：元データのPDF構造に応じて、シンプルな例（`extract_simple.py`）と座標ベースの例（`extract_coordinate.py`）のどちらを参考にするか判断する
- **フェーズ②（AI要約生成）**：抽出したデータをもとに、カードに表示する説明文をAIが生成する
- **フェーズ③（HTML生成）**：`build_html.py`をコピーして自治体固有の値を埋め、「📖 カードの説明」画面（コピー元自治体の文言が固定文字列で残っている）も対象自治体向けに書き換えた上で、最終HTMLを組み立てる
- **フェーズ④（公開）**：完成したHTMLを新規GitHubリポジトリにアップロードしGitHub Pagesで公開する。投票機能を使う場合は新規Supabaseプロジェクトも個別に用意する（本体ツールとは独立した環境で運用する設計）

カード内の項目（事業番号・担当課／タグ行／目的・事業内容／決算額・人件費表示／成果／廃止した場合の影響）は、`LABELS.show_*`で個別に表示・非表示を選べます。データの有無ではなく、制作者の好み（カードの情報量をどこまで絞るか）で決めてよい項目です。

## 自分の自治体版を作る

**対象読者**：AIコーディング支援（Claude Code等、コード実行可能な環境）が使える方。ブラウザのみのAIチャットでは、PDF抽出のデバッグ作業が現実的に困難です。

以下は👤（人間の作業）・🤝（AIから確認を受けながら進める協働作業）で大まかな役割分担を示す。

1. 👤 AIコーディング支援（Claude Code等）を開く（迷ったらデスクトップ等、分かりやすい場所で構わない）。「このリポジトリ（`https://github.com/onuma-spec/jimujigyou-hyoka-starter-kit`）をcloneして、スターターキット.mdを読んで、〇〇市を追加したい」と伝える。gitが使えなくてもAIがZIPを直接取得して展開できるので、事前のダウンロード作業は不要
2. 🤝 環境構築（Python 3系・`pdfminer.six`/`pymupdf`/`openpyxl`/`pandas`）を自分で済ませるかAIと一緒に確認・インストールするか選び、対象自治体の元データ（PDF等）が手元にあるか伝える。手元にない場合はAIと一緒にWeb検索で探す
3. 🤝 フェーズ①（取得・抽出）→②（AI要約生成）→③（HTML生成）を、要所でAIから確認を受けながら進める。北本市版（上記リンク）を完成イメージの見本にするとよい
4. 👤 フェーズ④（公開）：GitHubリポジトリとSupabaseプロジェクトの新規作成は、アカウントを持つ本人にしかできない作業なのでご自身で行う

詰まった場合は`fixed_prompt.md`の該当フェーズの記述に戻ってください。より詳細な手順（人間とAIの役割分担の全ステップ）は`スターターキット.md`の「作業手順（0〜6）」を参照してください。

## 公開後に表示設定だけ変更したい場合

評価カードのどのセクションを見せるか（事業番号・担当課／タグ／目的・事業内容／決算額・人件費／成果／廃止した場合の影響）は、公開済みのHTMLファイルに対して`patch_show_labels.py`（コマンドライン）または`patch_show_labels.html`（ダブルクリックでブラウザで開くだけ）で、データに触れずに何度でも変更できます。2026-08-04以降のテンプレートでビルドしたファイルが対象です。詳細は`スターターキット.md`の同梱ファイル一覧を参照してください。

## 免責事項

- 本リポジトリのコードは参考実装です。生成されるツールの内容（抽出結果・AI要約・タグ分類）の正確性は、公開前に必ず一次資料（自治体公表の評価シート原本）と照合してください。
- AIによる要約・分類には誤りが生じる可能性があります。住民に公開する前に、必ず人の目で内容を確認してください。
- 各自治体での公開・運用に伴う法令適合性・業務適合性の確認は、利用者の責任で行ってください。
